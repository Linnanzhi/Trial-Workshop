## 故障排查

### ❌ 获取验证码返回 403（额度不足）

**症状：**
```json
{
  "code": 403,
  "msg": "今日 AI 解析额度不足"
}
```

**解决方案：**
1. 检查今日剩余额度
   ```
   GET /api/ai-parse/remaining-quota
   ```
2. 等待明天额度重置
3. 或增加每日限额
4. 或充值 AI 账户

### ❌ 解析返回 500（API 错误）

**症状：**
```json
{
  "code": 500,
  "msg": "AI 服务调用失败"
}
```

**排查步骤：**

1. **检查 AI 配置**
   ```
   GET /api/ai-config
   ```

2. **测试 API 连接**
   ```
   POST /api/ai-config/test
   {
     "provider": "openai",
     "apiKey": "sk-xxx",
     "model": "gpt-4o-mini"
   }
   ```

3. **查看错误日志**
   ```bash
   tail -f logs/spring.log | grep -i "ai\|parse"
   ```

4. **常见原因：**
   - API Key 无效或已过期
   - 账户余额不足
   - 网络连接问题
   - AI 服务临时宕机

### ❌ 解析结果格式错误

**症状：**
```
题干识别错误
选项提取不完整
答案识别失败
```

**解决方案：**

1. **检查输入格式**
   - 确保题目结构清晰
   - 选项标记规范（A/B/C/D）
   - 答案标记清楚

2. **尝试其他 AI 服务**
   ```
   某个提供商可能识别能力更强
   ```

3. **人工审核和编辑**
   - 显示编辑界面
   - 允许用户修改识别结果

### ❌ 生成时间过长

**症状：**
```
等待 > 1 分钟还未返回
请求超时
```

**原因和解决方案：**

| 原因 | 解决方案 |
|------|---------|
| 网络延迟 | 检查网络连接，使用代理 |
| AI 服务繁忙 | 等待或换一个 AI 服务 |
| 输入太大 | 减少单次输入数量 |
| 超时设置过短 | 增加超时时间（在 application.yml 中） |

**增加超时时间：**
```yaml
# application.yml
spring:
  mvc:
    async:
      request-timeout: 120000  # 120 秒
```

## 常用测试命令
