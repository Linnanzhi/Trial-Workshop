## 功能概述

### 核心功能

✅ **文本解析** - 将纯文本自动转换为结构化题目  
✅ **多题型识别** - 自动识别单选、多选、判断等题型  
✅ **答案提取** - 智能识别答案和解析  
✅ **批量创建** - 一次性创建多个题目  
✅ **分类管理** - 自动分配到指定分类  
✅ **标签自动生成** - 根据题目内容生成标签  

### 应用场景

📚 **批量导入** - 大量试题快速导入题库  
📋 **试卷上传** - 直接解析试卷生成题目  
📄 **文档导入** - 支持 Word/PDF 文件  
🔄 **快速创建** - 手工输入文本快速创建题目

## 工作流程

```
用户输入文本
    ↓
提交到 /api/ai-parse/parse-text
    ↓
后端验证和预处理
    ├─ 检查文本有效性
    ├─ 估算 Token 消耗
    └─ 检查每日额度
    ↓
调用 AI 服务解析
    ├─ 发送文本到 OpenAI/DeepSeek/通义千问
    ├─ 使用提示词识别题型
    └─ 提取答案和解析
    ↓
结构化处理
    ├─ 验证解析结果
    ├─ 纠正格式错误
    └─ 生成标签
    ↓
返回题目列表
    ├─ 前端展示
    └─ 用户可调整后保存
    ↓
保存到题库
    └─ 关联到用户账户
```

{

## 解析规则

### 输入规范建议

为获得最佳解析结果，请遵循以下规范：

#### 1. 清晰的题目结构

```
✓ 好的格式：
1. 题干内容
   A. 选项1
   B. 选项2
   C. 选项3
   D. 选项4
   答案：C
   解析：解析内容

✗ 不好的格式：
(1)题干A选项1B选项2C选项3D选项4答案是C
```

#### 2. 标准的编号方式

```
✓ 推荐：
1. 题目1
2. 题目2
3. 题目3

✓ 也可以：
(1) 题目1
(2) 题目2
【1】题目1
【2】题目2

✗ 不推荐：
题目1
题目2
```

#### 3. 清晰的选项标记

```
✓ 推荐：
A. 选项1
B. 选项2
C. 选项3
D. 选项4

✓ 也可以：
A) 选项1
B) 选项2

✗ 避免：
1) 选项1
2) 选项2
```

#### 4. 明确的答案标记

```
✓ 推荐：
答案：C
答案：AC（多选）
正确答案：B

✗ 不标准：
答 C
选 B
应选 A
```

### 智能纠正

系统会自动纠正一些常见的格式问题：

```
输入的问题          自动纠正
─────────────────────────────
答案是 C      →    答案：C
答 C          →    答案：C
选项写反了    →    自动识别并纠正
标点符号错误  →    自动统一
重复内容      →    自动去重
```

### 准确度优化

- **单选/多选** - 准确度 95%+
- **判断题** - 准确度 98%+
- **填空题** - 准确度 85%（内容较开放）
- **简答题** - 准确度 80%（需要人工审核）

## 常见问题

### Q1: 如何提高解析准确度？

**A:** 
1. 使用清晰的文本格式（见上方规范）
2. 确保题干和选项完整
3. 选择准确度高的 AI 模型（OpenAI > DeepSeek）
4. 对重要的题目进行人工审核

### Q2: 如何处理解析失败的题目？

**A:**
1. 查看错误提示
2. 检查文本格式是否符合规范
3. 减少单次输入的题目数量
4. 尝试换一个 AI 服务

### Q3: 大量文本如何快速导入？

**A:**
1. 建议分批导入（每批 20-30 题）
2. 使用文件上传方式（支持大文件）
3. 设置较高的每日额度
4. 保存草稿并分次确认

### Q4: 可以批量编辑解析结果吗？

**A:**
支持批量操作：

```
1. 勾选需要编辑的题目
2. 点击"批量编辑"
3. 修改公共属性：
   - 分类
   - 标签
   - 难度
   - 题型
4. 保存更改
```
